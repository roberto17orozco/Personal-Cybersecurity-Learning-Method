# Cybersecurity projects

This directory contains a collection of hands-on cybersecurity projects aligned with the knowledge and practical skills developed through the **Google Cybersecurity Professional Certificate**.

Each project is organized within its own dedicated directory and includes documentation, screenshots, configuration notes, findings, and lessons learned collected throughout the implementation process.

The only exception is **Python Fundamentals**, which contains multiple standalone Python exercises and scripts. Rather than representing a single project, each script focuses on a specific Python concept such as variables, conditionals, loops, functions, file handling, exception handling, APIs, or automation fundamentals. Together, these exercises establish the programming foundation required for future cybersecurity, SOC, DFIR, and Threat Intelligence projects.
