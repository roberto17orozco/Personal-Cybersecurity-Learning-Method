# Cybersecurity projects

This directory contains several projects related to the topics covered in the Google Cybersecurity Professional Certificate.

Each project is stored inside its own dedicated directory and includes various documents related to the project itself. The only exception is **01_python_fundamentals_practice**, which contains multiple standalone Python scripts. Each script inside that directory represents an individual project on its own.

The projects listed in the table below are inspired by topics from the **Google Cybersecurity Professional Certificate** and were developed with the assistance of AI tools to enhance learning, structure, and documentation.




| # | Project | Scenario | Duration | SOC Tier | Alignment with Google CSPC | Best OS | Network | Traffic From Another Machine |
|---|----------|----------|----------|----------|---------------------------|----------|----------|----------|
| 1 | Wazuh SIEM (Rules + Detection) | Detect and investigate suspicious network activity, failed logins, and custom alert triggers | 4 days | Tier 1 | 95% | Kali Linux | Private | Yes |
| 2 | Security Onion (Zeek + Suricata) | Analyze network scans, suspicious connections, and IDS alerts generated from an attacker machine | 5 days | Tier 1.5 (Network SOC) | 90% | Kali Linux | Private | Yes |
| 3 | Velociraptor DFIR | Conduct post-incident forensic investigation using Windows artifacts and event logs | 4 days | Tier 2 (DFIR) | 80% | Kali Linux | Public | No |
| 4 | Sysmon + Elastic | Detect endpoint activity such as process creation, network connections, and suspicious command execution | 4 days | Tier 1.5 (Endpoint SOC) | 85% | Windows 11 | Private | Yes |
| 5 | AWS CloudTrail + VPC Flow Logs | Investigate cloud account activity, API usage, and network traffic in an AWS environment | 5 days | Tier 1.5 (Cloud SOC) | 90% | Kali Linux | Public | No |
