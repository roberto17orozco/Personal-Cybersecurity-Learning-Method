# Markdown basics
Markdown is a *markup language* that lets you format text using simple symbols. It can be used on any word processor. With the usage of symbols you are able to render the text you typed. Some of those symbols are:

### For Headings
* \#	Title 1
* \##	Title 2
* \###	Title 3
* ...
### Text style
* \*\*text**	**bold text**
* \_\_text__	__bold text__
* \*text*	*italics*
* \_text_	_italics_
* \*\*\* text***	***bolds + italics*** 
* \_\_\_text___	___bolds + italics___
* \~\~texto\~\~ strikethrough --->~~strikethrough~~
### Links
* \[text](http://text.com) regular link e.g. [google](google.com)
* \[text](http://text.com "Title") link with title e.g. [google](google.com "Google")
### Lists
* \*	bullet point
* \-	bullet point
* \+	bullet point
* [ 1. ] numeric bullet point
* [ 2. ] numeric bullet point
* [ 3. ] numeric bullet point
### Blockquote
* \>	use a blockquote, e.g. > this is a quote
e.g.
> this is a quote

### Code line
* \`text\`	`text`

### Checkboxes
* [ ] task pending
* [x] task completed 
### Escape characters
To show a symbol without being interpreted by Markdown use \ before the symbol
