# Nano basics
Nano is a text editor in command lines, it is simple, light and text can be edited in the terminals.


## Nano shortcuts

* `Ctrl + O` to save file.

* `Ctrl + X` to exit file or close file

* `Alt + 6` copy

* `Ctrl + U` paste

* `Alt + U` undo

* `Alt + E` redo


* `Alt + A` to start text selection at text cursor position. Use left, right, up and down keys to expand selection. Use it again to
**finish text selection.**

	* `Alt + A` + `Ctrl + End` to select from starting mark to the end of the file.

	* `Alt + A` + `Ctrl + Home` to select from starting mark to the begining of the file.

* `Shift + mouse` to select text with mouse.

* `End` key to go to the end of the current line.

* `Ctrl + End` to go to the en of the text.

* `Home` key to go to the begining of the line. 

* `Ctrl + Home` to go to the begining of the text.



## Modify the .nanorc file

Add this lines on file **/etc/nanorc** to:
* Enable mouse to set text cursor position: `set mouse`

* Enable `del` key to delete selected text: `set zap`
