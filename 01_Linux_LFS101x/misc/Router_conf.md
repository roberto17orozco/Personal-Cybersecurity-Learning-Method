# Router configuration.

This document describes how to configure a router for a better and faster performance.

## Identify the router you are using.

* Open `PowerShell` on Windows.
* `ipconfig`
* Locate **Default Gateway** on the Wi-Fi network adapter section, it will look something like this: 192.168.4.274. That is the default gateway and the IP for the router to enter to it's configuration interface.
* Enter that IP on your browser
* At this point you will be able to determine your router model, on this case it is a Huawei HG8245Q2.
* And by entering the router IP on your browser you can now configure it.

*Every different router models have different configuration interfaces and procedures*
