## Preview modes
### Shortcuts
* `Ctrl + Shift + V` is to open the file preview on a new window/tab.
* `Ctrl + K` and then `V` is to split the screen. On the left side you'll have the **Markdown** version and on the right side you will have the **Preview** version.
    * This is very usefull because you can see the preview in real-time.
* `Ctrl + Shift + P` to open the *Command Palette*, then type `>view: open preview` and select either `open preview` or `open preview to the side`.

### Graphical User Interface
You can access to this preferences through the *menu bar.*
* Go to `View` on the menu bar.
* Select `Open view...` and then type `>view: open preview` and select either `open preview` or `open preview to the side`.

A direct way to access to the `open preview to the side` mode is by clicking on the little book-with-a-search-tool-like-icon on the upper-right-corner of the file/tab you are working on.
